# AED-Bomberman

Proyecto de Bomberman en C++

## Estructura del proyecto

- `src/` : código fuente
- `include/` : headers
- `assets/` : recursos Raylib (imágenes, sonidos, etc.)
- `CMakeLists.txt` : configuración CMake

## Requisitos

- Compilador con soporte C++20
- CMake 3.16+
- Raylib para cargar assts
